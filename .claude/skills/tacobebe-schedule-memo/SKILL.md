# 타코베베 공구 일정·배너 메모 작성

## 1. 목적
구글 캘린더(takkobebe.official "장터캘린더(노출O)")에 적은 일정이 쇼핑몰 메인 배너·"곧 오픈해요"·공구 달력에
의도대로 뜨도록, 캘린더에 붙여 넣을 **제목 한 줄 + 설명란 몇 줄**을 만든다.
읽는 규칙은 `api/schedule.js` 에 있다. 보통은 코드를 고치지 않고 캘린더 글만 바꾼다.

## 2. 입력 받을 정보
- 상품명(손님에게 보일 이름), 공구 시작일·마감일 (종일 일정인지, 시간이 있는지)
- 상품 링크: 쇼핑몰 상품 주소 또는 외부몰 주소 (없으면 "쇼핑몰 검색으로 연결"이 되는데 틀릴 수 있다고 알린다)
- 외부몰 공구면: 공구가(최저가 옵션 기준), 정가, 배송 조건
- 배너에서 몇 번째로 보여야 하는지 (말이 없으면 비워 둔다)
- "배너가 이상해요" 문의면: 캘린더 제목·설명란을 그대로 복사해 받는다.

## 3. 작업 절차
1. 제목을 만든다 (4번 규칙). 손님에게 보일 상품명만 깔끔하게. 내부 메모는 설명란에 적는다.
2. 설명란을 만든다: 첫 줄에 링크, 그 아래 필요한 줄만 `이름: 값`. 내부 메모는 맨 아래에 두되 `가격·정가·배송·배너순서` 로 시작하지 않게, 주소(http)를 넣지 않게 쓴다 (설명란은 이 네 줄과 첫 주소만 손님 화면에 쓰인다).
3. 쇼핑몰 상품 링크는 `https://m.takkobebe.com/shop/detail.php?pno=...` 만 남겨도 된다 (뒤에 붙은 `cno1`, `rURL` 은 서버가 떼어 낸다).
4. 문구를 표시·광고 기준으로 점검한다 (6번).
5. 사용자가 캘린더에 붙여 넣으면 1~2분 뒤 `https://takkobebe-link.vercel.app/api/schedule` 결과에 반영된다. 결과를 열어 `title`·`url`·`sell`·`cons`·`ship`·`order` 값을 확인해 준다.
6. 캘린더 글로 안 되는 경우만 코드를 고친다 (CLAUDE.md 순서대로 브랜치 → PR):
   - 링크도 없고 검색으로도 못 찾는 상품을 고정 연결 → `MANUAL` 표에 한 줄
   - 사진·이름은 쇼핑몰 상품 것을 쓰고 누르면 외부몰로 → `LINK_OVERRIDE` 표에 한 줄
   - 설명란 없이 항상 맨 앞에 둘 상품 → `HERO_ORDER` 표에 한 줄
   - 각 줄 위에 `// 무엇 (날짜 사용자 요청)` 주석을 단다.

## 4. 타코베베 기준 (api/schedule.js 가 읽는 규칙)
제목:
| 쓰는 법 | 화면에서 |
|---|---|
| 제목은 한 줄로 | (여러 줄이 들어오면 첫 줄만 쓰고 나머지는 숨김) |
| 앞에 `1.` `2)` 번호 | 같은 날 시작한 일정의 순서. 번호는 화면에 안 보인다. 번호 없는 일정은 뒤로 |
| 끝 괄호 안에 `확인·결정·샘플링·게릴라·좋으면·넣기·마감이니·예정` 중 하나 | 괄호째 숨김 (예: `(가격 확인)`) |
| 제목에 `미정·휴가·연차·정산완료·명절판매` | 일정 전체가 안 보인다 |
| 그 밖의 괄호 `(2차)` `(500ml)` | 그대로 보인다 |
- 손님용 제목은 상품명 중심 25자 이내. "타코베베", "공구", "오픈", "마감", "n차" 같은 말은 검색 연결에서 빠지므로 상품명 낱말을 꼭 넣는다.

설명란 (한 줄에 하나, 콜론은 있어도 없어도 됨, 순서 상관없음):
| 줄 | 인정되는 이름 | 최대 | 화면에서 |
|---|---|---|---|
| (링크) | 처음 나오는 `http…` 주소 | — | 배너를 누르면 가는 곳 |
| 가격 | 가격, 판매가, 특가 | 30자 | 굵은 가격. 정가가 더 크면 할인율 자동 |
| 정가 | 정가, 원가, 소비자가 | 30자 | 취소선 가격 |
| 배송 | 배송 | 40자 | 상품명 아래 한 줄 (뒤에 D-day) |
| 배너순서 | 배너순서, 배너 순서 | 숫자 | 작을수록 메인 배너 앞 |
- `할인율` 줄은 읽지 않는다 (자동 계산). `배송비 4,000원` 처럼 이름 뒤에 글자가 붙으면 인식하지 않는다 → `배송: 4,000원` 으로.
- 쇼핑몰 상품은 가격·배송을 상품 페이지에서 자동으로 읽는다. 설명란에 적으면 적은 값이 우선이니, 쇼핑몰 상품에는 꼭 필요할 때만 적는다.
- 옵션이 여러 개면 최저가에 `~` (예: `52,200원~`). 고객은 가성비를 따지므로 정가는 실제 정가만 적는다.

## 5. 출력 형식
````
[캘린더 제목]
1. 설성목장 한우 불고기 부리또 2종

[설명란]
```
https://mall.sulsung.com/campaign/takkobebe-1
가격: 52,200원~
정가: 98,100원
배송: 5만 원 이상 무료배송 · 당일·새벽배송
배너순서: 2
(내부) 가격 9/30 확정 — 담당 확인
```
[화면 예상] 배너 제목 "설성목장 한우 불고기 부리또 2종" · 52,200원~ (정가 98,100원, 할인율 자동) · 배송 줄 + D-day
[점검] 표시·광고 n개 통과 / 확인 필요: (항목)
````

## 6. 금지 사항 / 점검 체크리스트
- [ ] 제목에 내부 메모(가격 미확정, 담당자 이름 등)가 없다. 메모는 설명란 아래쪽에, 필드 이름으로 시작하지 않게
- [ ] 숨기고 싶은 괄호에 4번 표의 낱말이 들어 있다 (아니면 손님에게 보인다)
- [ ] 가격·정가가 실제 판매 페이지와 같다. 정가가 부풀려져 할인율이 과장되지 않는다
- [ ] 배송 문구가 40자 안이고 약속 못 할 말("무조건 내일 도착")이 없다
- [ ] "최저가", "역대급", 근거 없는 "1위", 효능 표현("면역력")이 제목·배송 줄에 없다
- [ ] 어린이 용품이면 상세에 KC 인증·사용 연령이 있는지 함께 확인하라고 알렸다
- [ ] 캘린더 주소(iCal 비밀 주소)는 코드·채팅·PR 어디에도 적지 않았다 (환경변수 `GOOGLE_ICS_URL` 에만)

## 7. 좋은 예 / 나쁜 예
- 좋은 예: 제목 `2. 배도라지크림 (샘플링 확인)` → 화면 "배도라지크림", 같은 날 2번째.
- 나쁜 예: 제목 `배도라지크림 (샘플 받고 결정할지?)` — `결정` 이 있어 숨겨지긴 하지만, 이런 메모는 설명란으로 옮기는 편이 안전하다.
- 나쁜 예: 제목 `스텐 빨대컵 (가격 미정)` — 괄호만 숨는 게 아니라 `미정` 때문에 일정 전체가 안 보인다. → `스텐 빨대컵 (가격 확인)`
- 나쁜 예: 설명란 `가격은 18,100원부터` — 이름 뒤가 콜론·띄어쓰기가 아니라 "은"이라 읽지 못한다. → `가격: 18,100원~`
- 나쁜 예: 제목 `역대급 최저가! 부리또 공구 오픈` — 과장 표현, 상품명 낱말이 적어 검색 연결도 약하다.
