# 타코베베 스킬 제작

## 1. 목적
업무 설명을 받아, 매번 같은 품질로 처리되는 타코베베 전용 SKILL.md 완성본을 만든다.
결과물은 설명이 아니라 바로 저장할 수 있는 스킬 파일과 테스트 결과, 저장 카드다.

## 2. 입력 받을 정보
아래 중 모르는 것만 묻는다. 한 번에 최대 3개, 정보가 충분하면 묻지 않고 만든다.
1. 얼마나 자주 하는 업무인가, 결과물은 어디에 쓰이는가 (자사몰, 인스타, 공급사, 내부 보고)
2. 입력으로 무엇을 주는가 (상품 정보, 사진, 경쟁사 링크, 엑셀, 리뷰 원문)
3. 좋은 결과물 예시 또는 지금 불만인 점

## 3. 작업 절차
1. 중복 확인: 이미 있는 tacobebe-* 스킬과 겹치는지 본다. 겹치면 새 스킬 대신 기존 스킬의 개선본(전체 SKILL.md)을 만든다.
2. 범위 확인: 한 스킬은 한 업무. 업무가 2개 이상이면 나눌 스킬 이름과 경계를 먼저 제안한다.
3. 업무를 "입력 → 판단 → 출력"으로 쪼갠다. 판단 단계마다 숫자 기준을 정한다 (글자 수, 개수, 순서).
4. 5장 틀대로 SKILL.md를 쓴다.
5. 가상의 타코베베 상품 1개로 스킬을 그대로 적용한 결과를 보여 준다. 예시 상품은 실제 카테고리(먹거리·화장품·키즈 학용품·패션·영양제·생활용품) 안에서 고른다.
6. 테스트에서 걸린 점(빠진 입력, 애매한 기준)을 SKILL.md에 반영한다.
7. 사용자가 좋다고 하면 저장한다. Claude Code에서는 `.claude/skills/<스킬이름>/SKILL.md`로 저장해 PR을 올리고(세 계정이 같이 쓰게 됨), 일반 채팅에서는 저장 카드로 등록을 제안한다. 수정 요청이 오면 전체 SKILL.md를 다시 준다.

## 4. 타코베베 기준 (모든 스킬에 넣는 값)
- 고객: 30~40대 육아맘. 모바일, 짧은 틈에 봄. 안전·실사용 근거·가성비·공구 일정을 확인함
- 운영: 공구(오픈 예정·진행 중·마감) 중심 + 상시 판매. 자사몰 위사 m.takkobebe.com
- 톤: 다정하고 믿음직한 육아 선배 말투, 해요체, 과장 없음
- 컬러: #D1D798 연두, #161616 잉크, #7C8340 올리브, #F7F5EE 베이지
- 규격: 상세 이미지 1080px / 자사몰 상세설명 HTML 720px
- 화면 코드 수정(스킨, PR)이 필요한 업무는 스킬 대신 "takkobebe-link 프로젝트에서 진행"으로 안내한다. 코드 작업 스킬은 tacobebe-skin-edit, tacobebe-detail-desc가 있다.

## 5. 출력 형식
아래 순서 그대로 답한다.

1. 한 줄 설계: "이 스킬은 [입력]을 받아 [출력]을 만든다. [나눈 경우: 함께 쓸 스킬]"
2. SKILL.md 완성본 (코드블록 하나)
   ```
   ---
   name: tacobebe-<영문-소문자-하이픈>
   description: <언제 쓰는지 한 문장, 트리거 업무 단어 포함, 200자 이내>
   ---
   # 제목
   ## 1. 목적
   ## 2. 입력 받을 정보 (필수 / 있으면 반영 / 없을 때 질문)
   ## 3. 작업 절차 (번호)
   ## 4. 타코베베 기준 (톤, 규격, 고객 관점)
   ## 5. 출력 형식 (표·목록의 정확한 틀)
   ## 6. 금지 사항 / 점검 체크리스트
   ## 7. 좋은 예 / 나쁜 예 (표 3줄 이내)
   ```
3. 테스트: 가상 상품 입력 → 스킬 적용 결과 → 점검 결과 표
4. [확인 필요] 목록 (추측한 값)
5. 이 스킬 사용 예시 요청문 1~2개

## 6. 금지 사항 / 점검 체크리스트
작성 규칙
- "깔끔하게", "적절히" 같은 말 대신 숫자로 쓴다 (예: 제목 20자 이내, 한 섹션 3줄 이내).
- 입력에 없는 정보(수치·인증·후기)는 지어내지 말고 [확인 필요]로 두라는 지시를 넣는다.
- 분량은 A4 3장 이내.
- name에 claude, anthropic을 넣지 않는다.

카피·상세페이지 관련 스킬이면 6장에 반드시 넣을 점검
- [ ] 어린이제품 KC 인증 대상 여부, 인증번호 표기
- [ ] 사용 연령·소재·제조국·주의 문구 누락
- [ ] 의학적 효능 단정 금지 (아토피 개선, 면역력 향상, 키 성장, 집중력 향상 등)
- [ ] 최상급·절대 표현 금지 (100% 안전, 부작용 없음, 무독성, 국내 최고, 근거 없는 1위)
- [ ] 근거 없는 인증·수상·판매량 금지, 근거가 있으면 출처·기준일 표기
- [ ] 가짜 긴급성 금지, 공구 마감은 실제 날짜로
- [ ] 불안·죄책감 자극 금지 ("아직도 OO 쓰세요?", "엄마라면 꼭")
- [ ] 협찬·광고는 앞부분에 "광고/협찬"
- [ ] 화장품·세제·식품·영양제는 해당 법령 표시 기준 확인 안내
- [ ] 법적 판단은 "담당자 확인 필요"

## 7. 좋은 예 / 나쁜 예
| 나쁜 예 | 좋은 예 |
|---|---|
| "상품명을 매력적으로 작성한다" | "상품명 40자 이내, [타코베베] + 특징 1~2개 + 유형 + 용량" |
| 상세 기획·카피·촬영 컷을 스킬 하나에 | 기획안 / 카피 / 촬영 컷 리스트 3개 스킬로 나누자고 제안 |
| 테스트 없이 SKILL.md만 전달 | 가상 상품 1개로 돌린 결과와 점검 표까지 전달 |
